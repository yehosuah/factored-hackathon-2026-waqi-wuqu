# Fixtures

La verificación del entorno genera su fixture en un directorio temporal y la elimina.
No procede del organizador y no sirve como evidencia de calidad bancaria.

Identifica futuras fixtures con origen, propósito y semilla si usan aleatoriedad.
Esta carpeta está ignorada salvo este archivo. Para versionar una fixture pequeña y aprobada,
agrega una excepción explícita en `.gitignore` y revisa su contenido.
